About the project

Data science, given a face people trust

MindScore pairs a trained regression model with a calm, glass-panelled interface so the number it returns feels considered rather than clinical. Every field maps directly to a feature the model was trained on — no hidden weighting, no black box.

  • Model: Scikit-learn regression pipeline served via FastAPI
  • Interface: Hand-written HTML5, CSS3 and vanilla ES6+
  • Privacy: Stateless requests — nothing is logged or stored
